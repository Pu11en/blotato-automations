# Image-taste intake

Drop the two reference images here (or paste image URLs in the Discord thread and I
will download them). The image-taste flow reads local files:

- identity reference  -> the thing to keep exact (person/product/object)
- creative reference  -> the image whose structure/aesthetic to borrow

Example filenames:
  identity.png
  creative-direction.jpg

Then I run: reference_pack.py init/add -> generation.py prepare -> blotato plan/submit -> review.
